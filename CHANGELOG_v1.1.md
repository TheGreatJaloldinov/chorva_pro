# CHORVA PRO v1.1 changes

1. Replaced the main reply-keyboard navigation with inline buttons.
2. Added automatic/manual ID selection buttons.
3. Removed manual sex question. Sex derives from selected animal subtype:
   - Sigir: Urg'ochi
   - Buqa: Erkak
   - Qo'chqor: Erkak
   - Sovliq: Urg'ochi
4. Added Bilmayman buttons for optional/unknown breed, age, purchase date and purchase price.
5. Added O'tkazib yuborish buttons for photo and note fields.
6. Added add/replace/view photo actions to animal profile.
7. Moved search and archive actions to the bottom of the animal list keyboard.
8. Added message editing and best-effort removal of typed form replies to reduce chat clutter.
9. Improved emoji use in main menus and key forms.
10. Updated SQLAlchemy dependency to include asyncio extras (greenlet).
